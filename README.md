# student_exam_score_analysis

A Machine Learning web application built with **Streamlit** that predicts a student's exam score based on input features. The application uses a trained Scikit-learn model saved as `best_model.pkl` and provides real-time predictions through an interactive web interface.

## Live Demo
#website
https://exam-score-predictor1.streamlit.app/

---

## Features

- Interactive and user-friendly Streamlit interface
- Predicts exam scores instantly
- Uses a pre-trained Machine Learning model
- Fast model loading with Joblib
- Simple and clean UI
- Easy to deploy on Streamlit Cloud

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **Scikit-learn**
- **NumPy**
- **Joblib**
